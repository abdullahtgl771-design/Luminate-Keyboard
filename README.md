# Luminate Keyboard

Android custom keyboard (IME) project.

- App name: Luminate Keyboard
- Application ID / namespace: `com.luminate.keyboard`
- Minimum SDK: 24
- Target SDK: 34

## Build

```bash
gradle assembleDebug --no-daemon
```

The GitHub Actions workflow in `.github/workflows/build.yml` builds a debug APK on push or manual dispatch.
